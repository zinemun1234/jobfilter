Build & Data Linking

02
03 build 실패 해결

getServerSession이나 headers를 사용하는 라우트에서 static prerender 오류가 발생했다. export const dynamic = 'force-dynamic'를 추가하고, useSearchParams를 사용하는 client 페이지는 Suspense boundary로 감쌌다.

04 데이터 모델 변경

Prisma 스키마에서 Portfolio, Experience, InterviewAnswer에 jobId 컬럼을 추가하고, JobPosting과의 관계 및 인덱스를 추가했다. migration 파일 20260813000000_add_job_id_links을 생성하여 Supabase 운영 DB에 적용했다. 기존 데이터는 그대로 유지한다.

Security & Operations

03

API 권한/인증 통일

lib/api.ts에 requireAdmin(), requireAdminOrOwner(), sanitizeUser(), sanitizeJobPosting()을 추가하고 15개 관리자 API에서 사용하도록 통일했다.

비밀번호 재설정

devToken 응답 제거, 안내 메시지 반환, /forgot-password와 /reset-password를 /login으로 리다이렉트.

06 GitHub 분석 보호

lib/github-analysis.ts에 5초 timeout, redirect 추적, 5MB 크기 제한, rate limit 상태 관리, 7일 캐싱을 적용했다. 응답 파싱 실패, timeout, rate limit 시 null을 반환한다.

07 알림 모델 구조화

UserNotification에 type, referenceId, actionUrl 컬럼을 추가하고 @@unique([userId, type, referenceId]) 제약을 설정했다. lib/notifications.ts를 upsert 기반으로 개편했다.

08 JSON 파싱 공통화

lib/json-utils.ts에 safeJsonParse(), parseJsonArray(), stringifyJson()을 추가하고 app/api/jobs/[id]/route.ts에 적용했다.

E2E & Next Steps

브라우저에서 /jobs → /portfolio → /cover-letter → /interview → /jobs/[id] 순서로 흐름을 확인했다. 공고 연결, 저장, 상세 페이지 표시 모두 정상 동작했다.
