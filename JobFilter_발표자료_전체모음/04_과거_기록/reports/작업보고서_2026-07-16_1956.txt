프로젝트 개요

JobFilter는 컴퓨터공학부 학생을 위한 맞춤 취업 공고 필터링 & 자소서 코칭 웹앱입니다.
기술 스택은 Next.js 14(App Router), React, TypeScript, Tailwind CSS, shadcn/ui, Prisma, NextAuth.js, PostgreSQL(Supabase)를 쓰고 있고, Vercel에 배포돼서 2026.05.22부터 실서비스 운영 중입니다.


디자인 작업

전체 UI는 Tailwind CSS 기반으로 깔끔하게 잡았습니다. shadcn/ui와 Radix UI 프리미티브를 써서 Button, Card, Dialog, Select, Tabs 같은 컴포넌트를 통일감 있게 맞췄고, 라이트/다크 모드 둘 다 지원하도록 globals.css에 oklch 기반 CSS 변수로 색상 토큰을 정리했습니다.

대시보드 레이아웃은 (dashboard)/layout.tsx에서 flex h-screen 구조로, 왼쪽에 Sidebar, 오른쪽에 메인 콘텐츠 영역을 두고 모바일에서는 BottomNav가 나오도록 했습니다. 배경은 radial-gradient로 블루/바이올렛 톤을 깔아서 좀 더 산뜻하게 만들었고, 카드 UI는 rounded-xl, border-gray-100, bg-white, shadow-sm 패턴을 페이지마다 반복해서 썼습니다.

타이포그래피는 text-gray-900 / 500 / 400 정도의 단계로 정보 우선순위를 표현했고, 섹션 라벨은 uppercase tracking-widest로 처리했습니다. 스크롤바도 회색 thumb에 둥근 모서리로 살짝 커스터마이징했습니다.

주요 페이지는 cover-letter/export, bookmarks, calendar, dashboard, interview, jobs, listings, notices, notifications, portfolio, profile, roadmap 등이 있고, 전부 비슷한 카드/테이블/폼 스타일로 맞춰뒀습니다.


자소서 PDF 내보내기 한글 깨짐 해결

문제
- PDF를 다운로드하면 한글이 사각형으로 깨져서 나왔습니다.

원인
- @react-pdf/renderer의 기본 폰트가 Helvetica인데, Helvetica는 한글 글리프가 없어서 한글을 그릴 수 없었습니다.

조치
- app/(dashboard)/cover-letter/export/page.tsx에서 Font.register로 Noto Sans KR을 등록했습니다.
  - Regular(400): https://fonts.gstatic.com/s/notosanskr/v39/PbyxFmXiEBPT4ITbgNA5Cgms3VYcOA-vvnIzzuoyeLQ.ttf
  - Bold(700): https://fonts.gstatic.com/s/notosanskr/v39/PbyxFmXiEBPT4ITbgNA5Cgms3VYcOA-vvnIzzg01eLQ.ttf
- StyleSheet의 fontFamily를 Helvetica에서 NotoSansKR로 바꿨고, 굵은 글씨는 fontWeight: 700로 처리해서 Helvetica-Bold는 제거했습니다.

결과
- PDF에 회사명, 직무, 질문, 답변, 글자수까지 한글이 정상적으로 출력됩니다.


변경 파일

- app/(dashboard)/cover-letter/export/page.tsx
  - Font import 추가
  - Font.register(...) 추가
  - fontFamily 및 fontWeight 수정


참고

- Google Fonts CDN URL에는 v39 같은 버전이 들어가 있어서, Google Fonts 쪽 경로가 바뀌면 404가 뜰 수 있습니다.
- 장기적으로 안정적으로 쓰려면 public/fonts/에 Noto Sans KR Regular/Bold 파일을 직접 넣고, Font.register의 src를 '/fonts/NotoSansKR-Regular.ttf' 같은 상대 경로로 바꾸는 게 더 안전합니다.
- 현재 public/fonts/ 디렉토리는 만들어져 있지만 비어 있습니다.
