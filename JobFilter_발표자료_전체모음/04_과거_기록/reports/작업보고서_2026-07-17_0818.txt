프로젝트 개요

JobFilter는 컴퓨터공학부 학생을 위한 맞춤 취업 공고 필터링 & 자소서 코칭 웹앱입니다.
기술 스택은 Next.js 14(App Router), React, TypeScript, Tailwind CSS, shadcn/ui, Prisma, NextAuth.js, PostgreSQL(Supabase)를 쓰고 있고, Vercel에 배포돼서 2026.05.22부터 실서비스 운영 중입니다.

이번 작업은 추천기능_상세구현계획.txt의 Phase 1과 Phase 2 기능을 AI API 없이, 서버 비용 0원 원칙 하에서 룰/키워드 기반으로 구현하는 것입니다. AI나 외부 스케줄러(cron)가 필요한 기능은 후속 검토 대상으로 남겨두었습니다.

지금 당장 지원해야 할 공고 우선순위 점수

목적
- 단순 마감 임박순이나 매칭률순이 아닌, 다중 지표로 우선순위를 산출해 대시보드 상단에 노출해야 합니다.

조치
- app/api/dashboard/priority-jobs/route.ts에서 아래 3가지 점수를 계산합니다.
  - fitScore: 사용자 skills와 JobListing.tags의 교집합 비율 (0~100)
  - urgencyScore: 마감일까지 남은 일수 (7일 이하=100, 30일 이상=30, 그 사이 선형)
  - competitionScore: 북마크 수 기반 역수 (0개=100, 10개 이상=0, 1개당 10점씩 차감)
  - priorityScore = fitScore * 0.5 + urgencyScore * 0.3 + competitionScore * 0.2
- Prisma _count.bookmarks로 북마크 집계를 수행했습니다.
- 상위 5개를 priorityScore 기준으로 정렬해 반환합니다.
- components/dashboard/PriorityJobCard.tsx를 만들어 순위, 회사/직무, priorityScore, 세부 점수, D-day, 북마크 수, 태그를 표시합니다.
- components/dashboard/PrioritySection.tsx에서 React Query로 /api/dashboard/priority-jobs를 호출하고, 로딩/빈 상태를 처리합니다.
- app/(dashboard)/dashboard/page.tsx의 히어로 배너 아래 max-w-5xl 영역에 <PrioritySection />을 삽입했습니다.

결과
- /dashboard 접근 시 우선순위가 높은 공고 5개가 "오늘의 추천 공고" 섹션으로 노출됩니다.
