1. 공고 변경 감지 (Diff 알림) — 1순위

목적
- 사용자가 북마크한 공고의 JD/마감일이 변경되면 알림으로 알려줍니다.
- 학교 취업지원처 엑셀은 특정 시점 스냅샷이기 때문에, 기업이 공고를 수정하거나 조기 마감할 경우 대응이 늦어질 수 있습니다.

배경
- 현재 북마크는 저장만 되고, 원본 URL의 변경 여부는 추적하지 않습니다.
- 조기 마감이나 JD 수정은 서류/면접 준비에 직접 영향을 줍니다.

조치
1. Prisma schema의 `JobBookmark` 모델에 `lastCheckedAt`, `lastContentHash` 필드를 추가합니다.
2. `POST /api/cron/job-change-detection` API를 추가합니다.
3. 북마크된 `JobListing.url`을 fetch하여 본문 텍스트를 추출합니다.
4. 추출한 텍스트를 정규화(공백 제거, 소문자 변환)한 뒤 SHA-256 해시를 생성합니다.
5. 이전 해시와 다르면 변경으로 간주하고 `UserNotification` 레코드를 생성합니다.
6. 변경된 부분은 `diff-match-patch` 또는 `diff` 패키지로 before/after 요약을 생성합니다.

적용 기술
- 데이터 저장: Prisma, PostgreSQL
- 스케줄링: Vercel Cron 또는 node-cron(배포 환경에 따라 분기)
- 본문 추출: Node.js fetch + cheerio 또는 html-to-text
- 해시 비교: crypto.createHash('sha256')
- diff 출력: npm diff-match-patch 또는 diff
- 알림: 기존 UserNotification 테이블

API 설계
- `POST /api/cron/job-change-detection`
  - 입력: 없음(cron 트리거)
  - 로직: 북마크된 공고 중 `lastCheckedAt`이 6시간 이상 지난 항목만 fetch
  - 결과: 변경된 공고에 대해 notification 생성
- `GET /api/notifications` (기존)
  - diff 요약(예: `변경: 마감일 2026-08-01 → 2026-07-25`) 포함

변경 파일
- `prisma/schema.prisma`: `JobBookmark` 필드 추가
- `app/api/cron/job-change-detection/route.ts`: 신규
- `app/(dashboard)/notifications/page.tsx`: 공고 변경 알림 카드 추가
- `app/api/notifications/route.ts`: diff 요약 포함

DB Schema 변경

}

  ...
  previousDescription String? // 이전 본문(선택, diff 용)

기대 효과
- 북마크한 공고의 변경 사항을 누락하지 않고 확인할 수 있습니다.
- 공고 마감일 연장이나 조기 마감에 신속히 대응할 수 있습니다.

참고

2. 우선순위 점수 가중치 사용자 조절 — 2순위

- 고정 가중치는 개인별 우선순위를 반영하지 못합니다.

4. API 내부에서 `priorityScore = fit * w1 + urgency * w2 + competition * w3`을 계산합니다.

7. 엑셀 업로드 인코딩/CSV 강화 — 7순위

목적
- 학교 취업지원처에서 받은 엑셀/CSV 파일의 인코딩(euc-kr 등)과 구분자, 따옴표, 줄바꿈 처리를 강화합니다.

배경
- 현재 `/api/admin/listings/upload`는 UTF-8 CSV를 직접 파싱합니다.
- 실제 기관 파일은 euc-kr, 쉼표 포함 셀, 줄바괄온 따옴표 등이 섞여 있을 수 있습니다.
- 한글 깨짐이나 컬럼 오류는 등록 실패로 이어집니다.

조치
1. `iconv-lite`를 추가해 인코딩을 자동 감지/변환합니다.
2. CSV 파서를 csv-parse 등 안정적인 라이브러리로 교체합니다.

4. 컬럼명 자동 매핑을 더 많은 동의어로 확장합니다.
5. 업로드 미리보기에 파싱 오류 행(row index, raw)을 표시합니다.

적용 기술
- 인코딩 변환: iconv-lite
- CSV 파싱: csv-parse 또는 papaparse
- 엑셀 파싱: xlsx(기존)
